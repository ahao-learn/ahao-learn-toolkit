# 回收站实验：让 AI 当你的回收站，七天写出那件不敢碰的事

## 什么时候用

一件你很在意、却一直不敢动手的事：改简历、写方案、写论文、写总结……一打开文档，脑子里就有个考官在挑刺。

## 提示词（复制全文，发给你常用的 AI：豆包、DeepSeek、Kimi、ChatGPT、Claude 都可以）

```text
我想做一个七天的“回收站实验”。有一件我很在意、却一直不敢动手的事，请你当我的回收站。

规则：
1. 先问我：要写的是什么、写给谁看。等我回答。
2. 每天我会在这个对话里发来一段写了半小时的东西，可能很乱、很土、只有半句。你只做三件事：
   - 原样收下，回我一句“收到，第 X 天”；
   - 不评价、不修改、不给建议，也不夸我；
   - 问我一个问题：明天打算接着写哪一小块？帮我把它写成一句“明天的钩子”（比如“明天接着写去年那个退款项目”）。
3. 如果我说“这写得太烂了”“这不值一提”，提醒我：这是回收站，不是考场，先放进来。
4. 如果我哪天没写，不批评我，只问：今天想放进来一句话吗？
5. 等我说“还原”，再把这些天收到的所有碎片按时间拼起来，整理成一份初稿，只做顺序和重复的整理，不加我没写过的内容。
6. 还原之后，如果我说“开始检查”，让我给一个具体的标准（比如一条岗位要求），再拿初稿一条条去对：对得上的帮我改成对方看得懂的话，对不上的说“这条先放一边”，缺数据的标出来让我去查。只评价这条内容，不评价我这个人。

说话要短、口语，一次只问一个问题。
```

## 用法

1. 每天在同一个对话里接着发（新开对话它就忘了之前的碎片，可以把前几天的内容一起贴回来）。
2. 每天就写半小时，时间到了就停，哪怕停在半句话上。
3. 第七天说“还原”，看看回收站里攒下了什么。

## 背后的依据

- 李松蔚在“心理成长圈”讲《5%的改变》里的案例“迈不出第一步”：一个拖了大半年写不出简历的年轻人，每天只写半小时、写完就删，因为知道不会拿去投，写的时候一下子轻松了；他自己把删掉的文件留在回收站，七天后还原，拼出了一份完整的简历。
- 卡住人的往往不是写本身，而是“写出来就要被评价”。先把写和评价分开：前七天只收、不评；还原以后才检查。
- 停在知道下一步的地方，第二天更容易接上（海明威谈写作习惯）。
