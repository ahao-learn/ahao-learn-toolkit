# 找一个正在做的人聊聊

## 一、为什么这一步最划算

Gilbert 等（2009，《科学》）让哈佛学生预测 5 分钟速配约会后自己会多开心。看对方资料和照片的人，预测误差是只看“上一个约完的人打的开心分”的人的两倍左右；可 75% 的人觉得看资料更准。两件小事上的实验，推到选工作是同一个思路的类推，但道理相通：别人刚经历过的真实感受，往往比你在脑子里的想象准。

聊半个小时，比在网上搜一个星期行业前景更能打破不切实际的幻想，或者没必要的恐慌。

## 二、找谁

先从已经说得上话的人里找，不先找陌生人和行业大佬：

- 同学、前同事、以前对接过的人；
- 朋友的朋友（请朋友转一句）；
- 家里人认识的人。

最好是在这行干了一两年、还记得刚入行是什么样的人。

## 三、怎么开口

帮用户写一句，原则是：说清不是求职、时间短、对方怎么方便怎么来。例：

> 你好，我最近在想以后的方向，对你在做的这行挺好奇，想听你讲讲平时具体在忙什么，不是找工作。占你十五分钟，你方便的话语音回几条也行。

发五个、回两个就算顺利。没人回，不是用户的问题，换下一个。

## 四、聊什么

不问宏大的前景，听他讲最具体的日常：

1. 你平时一天大部分时间在忙什么？
2. AI 在你的活里帮上了哪些忙？哪些还得你自己来？
3. 这行现在还招不招新人？新人进去头几个月一般做什么、最容易栽在哪？
4. 你刚入行时最难的是哪一段？现在还难吗？
5. （可选）如果重来，你还会选这行吗？

一次聊天不用问完，顺着对方说的往下问。

## 五、聊完记什么

让用户贴回来，存进 `聊过的人.md`：

```
<日期> 和 <谁（不写全名也行）> 聊
他每天主要在：……
AI 帮得上的：……　还得人来的：……
新人：……
最让我意外的一句：……
听完我更想靠近 / 更想躲开，因为：……
```

最后一行最重要。下一步挑什么小东西来做，常常就从“最让我意外的一句”里来。
