# 第四周：一起看

## 一、摊开什么

`方向.md`、`聊过的人.md`、`小东西.md`（做出来的东西本身）、`记录/` 里的每一天。

## 二、按这几个问题过一遍

1. 小东西交出去了吗？给谁看了？对方说了什么？
2. 记录里，投入程度高、做完精力反而多了的是哪几天？那几天在做什么？
3. 碰到的难，多数是方法的问题，还是事情本身的问题？
4. 和正在做的人聊完，你是更想靠近，还是更想躲开？
5. 如果现在按这个节奏再试四周，你的第一反应是“行吧，还可以”，还是“千万别”？

## 三、三选一

- **再试四周**：第 5 题是“还可以”，哪怕没有很兴奋。下一个四周把小东西做大一点，或者再找一个人聊。
- **换一个方向**：小东西交出去了、难多半是事情本身的、第 5 题是“千万别”。回到 `method.md` 第三节，挑下一个。
- **先停**：生活上有别的事要先处理。停也算做完了一次实验。

还有一种情况：小东西没做出来。那是这次没测到这个方向，不是方向不行。把小东西缩小一档，同一个方向再试一次。

## 四、结论只说这个方向

写进 `复盘.md` 的结论，只说“这四周、这个方向、这种做法，我要不要继续”，不写“我这个人就是什么都不喜欢”。四周、一个方向、一两件小东西，样本太小，说明不了一个人。

用户说出“我果然什么都不行”时，一句话挡回去：“这四周说明的是这个方向，不是你。我们看看下一个。”

## 五、复盘模板

```
方向：……　第 N 个四周
做出来的：……　给谁看了：……
投入最高的几天在做：……
难多半是：方法的问题 / 事情本身的问题
结论：再试四周 / 换方向 / 先停
下一步：……
```
