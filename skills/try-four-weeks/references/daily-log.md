# 每天记两三句

## 为什么记

四周以后回头看，靠的是记录，不是印象。人对“这段时间感觉怎么样”的回忆很容易被最后几天或者最难受的一天带偏。

《斯坦福大学人生设计课》里有个工具叫“美好时光日志”：每天记下做了什么、那时有多投入、做完精力是多了还是少了。这里用简化版。

## 模板

用户睡前发来，原样存进 `记录/第N天.md`：

```
第 N 天 <日期>
今天做了：……
投入程度（1—5）：……
做完精力：多了 / 差不多 / 少了
卡在哪：……
```

一句也行。漏了不追问，只问一句“今天想补一句吗？”

## 你怎么回

只回“记下了”，再问一个明天的小问题（“明天打算先做哪一小块？”）。不点评、不总结、不鼓励。

## 第四周怎么用

看三样：哪几天投入程度高、做完精力反而多了，那天在做什么；“卡在哪”里出现最多的是什么；是方法的问题多，还是事情本身的问题多（见 `small-project.md` 第三节）。
