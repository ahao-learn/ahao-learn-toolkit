# 边试边学：先计划，还是先试？

用在用户坚持“我得先想清楚再动”的时候，或者做了很多测评、读了很多书还是没答案的时候。

## 一、两种改变的方式

研究职业转型的学者 Herminia Ibarra（伦敦商学院，《转行》，英文 *Working Identity*）访谈了一批成功转行的人，发现多数人不是先想清楚再行动，而是边试边弄清楚。陈海贤（心理成长圈《每天懂点心理学》）讲这本书时，把两种方式做了对比：

| | 先计划，再行动 | 边试边学 |
|---|---|---|
| 起因 | 对现状不满 | 越来越清楚的各种可能 |
| 从哪开始 | 内部：调整心态、反思 | 外部：先行动 |
| 次序 | 直线：设目标 → 定计划 → 执行 | 循环：做 → 反思 → 修正方向 |
| 目标 | 固定，达不到就是失败 | 变化的，不断测试新的可能 |
| 需要的信息 | 明确的信息 | 模糊的信息就够：知道自己对什么感兴趣、从哪开始 |
| 怎么认识自己 | 通过反省发现“真实的自我” | 通过尝试塑造新的自我 |

“以后干什么”这类问题，信息永远不会先变明确，所以第二种更合用。（Ibarra 的结论是访谈归纳，不是实验。）

## 二、书里的两个例子（陈海贤转述）

- **加里**：35 岁的商业顾问，被老板差评后开始反思。做职业测试没得到答案；从兴趣出发试了高端红酒生意、潜水教练，都行不通；又回去面试老行业，拿到 offer 还是不喜欢。一路试、一路认识人，最后接到一家公司的邀请，正好是他喜欢的工作。
- **一位学员**：在房地产公司做设计，辞职换了很多工作，三年后回到原来的公司，这次却很喜欢这份工作。他说这三年不是浪费：不出去试，就不知道向往的工作是什么样，也不知道自己其实喜欢现在的工作。

## 三、计划好的偶然

职业咨询学者 Krumboltz 等人提出：偶然在每个人的职业里都很重要，与其想消除偶然，不如多做探索性的事，提高遇到好机会的概率；咨询的目标是让人学会行动，而不是做出一个“唯一的职业决定”。（理论文章，没有实验检验。）

对用户的意思是：多出门、多聊、多试，好机会常常是在做这些事的时候撞上的（`prototyping.md`、`small-bets.md`）。

## 四、陪用户时

- 用户说“等我想清楚”：把上面的表讲成一两句，“这种问题靠想是想不清楚的，要靠试”，然后问“这周能试的最小一步是什么？”
- 边试边学不是乱试：每次试完都要问“我学到了什么、下一步往哪试”（`prototyping.md` 的记录模板）。
