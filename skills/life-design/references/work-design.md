# 找到好工作，改造现在的工作

## 一、找工作：别只盯着招聘信息

只看网上的招聘信息、海投简历，命中率很低；很多好机会是在和人的交流里出现的。原型对话（`prototyping.md`）做得多了，常常会有人说“我们这里正好需要人”，而那个位置可能从来没有公开招聘过。

所以：

- 求职阶段也继续做原型对话，问的是对方的工作和故事，不是“你们招不招人”。
- 对方主动聊到机会时，再表达兴趣。
- 投简历时，用聊天里听到的真实需求去写，而不是照抄招聘要求。

## 二、改造现在的工作

很多人不需要换工作，而是需要换一种做法：

1. 用仪表盘和美好时光日志，看清工作里哪些部分让你有劲、哪些耗人（`dashboard.md`、`good-time-journal.md`）。
2. 用 AEIOU 找出原因：是活动本身、环境、和谁共事，还是为谁服务。
3. 在现有岗位里调整比例：主动多接让你有劲的活，和领导商量少做耗人的部分；换一个更适合的环境或合作对象。
4. 调整不了，再考虑换，而且先在业余时间做原型。

比如一位精算师，喜欢的是独自解决复杂的专业问题，耗人的是行政和沟通。他最后换的是工作方式，不是行业。

## 三、提醒

- 不鼓动辞职。换工作之前先试，试的代价要赔得起。
- 收入、地点、家人这些现实条件，先摆出来，属于重力问题的就接受（`reframes.md`）。
