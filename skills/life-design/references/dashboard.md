# 仪表盘：先看清现在在哪

出自《斯坦福大学人生设计课》第 1 章。人生设计的起点不是你希望到达的地方，更不是你认为自己应该在的地方，而是你当下所处的真实位置。

## 一、四个仪表

让用户画四格，每格给现在打 0—10 分，再写一两句为什么：

1. **健康**：身体、心理、情绪。最近有没有足够的锻炼和休息？精力怎么样？情绪稳不稳？
2. **工作**：学业也算。享不享受？觉得有没有意义？压力怎么样？
3. **娱乐**：只为了快乐而做的事。书里特别说：如果做一件事是为了赢、进步或达成目标，即使很开心，也不算娱乐。最近有没有这样的时间？
4. **爱**：和家人、朋友、伴侣的关系。能不能感到爱和被爱？

## 二、怎么看

- 不追求四个都满分。看哪一格最低、哪一格让他最在意。
- 问：“哪一格的分数，最让你意外？”
- 常见的发现：以为问题在 A，其实在 B。课程里的个案：一位成绩很好的研究生，导师以为她是感情受挫，评估后发现真正的问题是她并不喜欢自己的专业，只是一直在努力把它做好——这就是“灾难性的成功”。
- 有一格很低、又是改变不了的现实时，按重力问题处理（`reframes.md` 第三节）。

## 三、接下来

- 工作格低：去 `good-time-journal.md` 找具体是哪些事耗人。
- 说不清自己想要什么：去 `compass.md`。
- 过几周再打一次分，看有没有变化。存进 `仪表盘.md`，写上日期。

## 模板

```
<日期>
健康：_/10　因为……
工作：_/10　因为……
娱乐：_/10　因为……
爱：_/10　因为……
最在意的一格：……
```
