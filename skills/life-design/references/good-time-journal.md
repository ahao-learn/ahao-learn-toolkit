# 美好时光日志：从日常里找线索

寻路的关键：跟随快乐前行，做能吸引你、让你兴奋、激发你活力的事。

## 一、记什么

连续记一到三周，每天晚上花几分钟。每条记两样：

1. **在做什么**：开会、写报告、和家人吃饭、打球、帮朋友修电脑……
2. **两种体验**：
   - **投入程度**：有没有忘了时间、注意力很集中、几乎忘了自己——这就是心流的感觉。
   - **能量**：做完以后，精力是多了，还是被掏空了？

## 模板

```
<日期>
活动：……　投入 1—5：_　能量：多了 / 差不多 / 少了
活动：……　投入 1—5：_　能量：多了 / 差不多 / 少了
今天最投入的一刻：……
```

## 二、一周后看

- 投入高、能量也多的事，是什么？
- 哪些事一做就耗人？
- 同一件事，什么时候让人有劲、什么时候耗人？差别在哪？

## 三、AEIOU：把镜头拉近

看清了“哪些事”以后，用五个问题看“为什么”：

- **A 活动**：具体在做什么？是一个人做还是一群人？是你主导还是配合？
- **E 环境**：在哪？安静的地方还是嘈杂的地方？
- **I 互动**：和谁在一起？和什么样的人互动让你有劲、什么样的耗人？
- **O 物件**：在用什么东西——电脑、纸笔、工具、机器？
- **U 使用者 / 服务对象**：在为谁做？

例子：一位精算师很不快乐，以为是不喜欢这份工作。记了日志、用 AEIOU 一看，发现他喜欢的是安静地解决复杂的专业问题，耗人的是繁琐的沟通和行政事务。他没有离开这一行，而是换了一份大部分时间独自处理专业难题的工作，状态好了很多。

## 四、提醒

- 人生设计不一定是大改变。很多时候是调整每天的比例：多做让你有劲的事，少做耗人的事。
- 用户说“记不住”，降到每天一条也行。漏了不追问。
- 记录攒够了，可以拿它做思维导图（`mind-mapping.md`）。
