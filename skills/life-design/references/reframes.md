# 重新定义问题

## 一、为什么要重新定义

设计思维的核心动作：拿到新信息后，换一个角度理解问题，解法就跟着变了。书里的例子：问发明汽车之前的人想要什么，回答是“一匹更快的马”；问想做什么，回答是“更快地到达”。名词变成动词，问题就被重新定义了。

在人生设计里，重新定义有两种用法：找到真正的问题；把卡住人的想法换个说法。

## 二、常见思维误区和重新定义

| 思维误区 | 重新定义 |
|---|---|
| 我应该已经知道自己要去哪了 | 只有知道自己现在在哪，才知道怎么去目的地（`dashboard.md`） |
| 太晚了 | 设计一种自己喜欢的生活，什么时候都不晚 |
| 我得先找到热爱，才能开始 | 热爱多半是做出来的，先试 |
| 我必须找到那个唯一正确的方向 | 你有很多种可能的人生，可以选其中一种，以后还能再改 |
| 我陷入了困境 | 我从来不会被困住，因为我总能想出很多点子（`mind-mapping.md`） |
| 我得想清楚再动 | 想不清楚的事，可以试清楚（`prototyping.md`） |
| 工作本来就不该有乐趣 | 乐趣是线索，会把你带到适合的方向（`good-time-journal.md`） |
| 我已经在这条路上投入太多了 | 越早发现方向不对越好；在错的路上一直成功，书里叫“灾难性的成功” |
| 我要选最好的那个 | 选一个足够好的，然后放下（`choosing.md`） |
| 这次失败说明我不行 | 失败是原材料，看看它属于哪一类（`failure-reframe.md`） |

用法：先听用户的原话，找到他正在用的那个误区，用一句话说出重新定义，再给一个这周能做的小动作。不一次念整张表。

## 三、重力问题

书里的话：“如果一个问题不能被解决，那么它就不是一个问题。它只是一种情况，一种生活现实；它像重力一样。”

- 例：想当消防员但有比较重的哮喘，过不了体能测试。
- 应对：接受它，不再跟它较劲，把力气用在能动的部分。那位朋友后来做了消防安全顾问，给学校做培训（课程里钱炜讲的例子）。
- 怎么分辨：问“如果你拼尽全力，这件事有没有可能改变？”没有，就是重力问题；有、只是很难，就不是。
- 注意：很多看起来像重力的问题，其实是“很难但能动”的。不要轻易判成重力问题，让用户自己判断。

## 四、锚问题

书里的定义：一个现实问题，其实能解决，但因为被困在一个固定的解法上太久，觉得它难以逾越。例：一直觉得“只有考上某个证书才能换工作”。

- 应对：不在原来的解法上用力，先想出很多别的可能（`mind-mapping.md`），挑一个做小原型。
- 书里两条原则：好点子要足够多，才能从中选出更好的；对任何问题，都不要选第一个解决方案。
