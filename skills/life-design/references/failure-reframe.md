# 失败重构

出自《斯坦福大学人生设计课》第 10 章“你可以对失败免疫”。书里的说法：失败是创造成功的原材料，失败重构是把原材料转化成成长的过程。

## 一、三步

1. **记下失败**：最近一段时间里，让他觉得失败的事，一条一句。
2. **分类**：
   - **失误**：平时能做好、这次搞砸了的。下次注意就好，不用深挖。
   - **弱点**：反复出现、一直没改掉的。接受它，想办法绕开或者少碰。
   - **成长机会**：本可以做得不一样、而且值得学的。只在这一类上花力气。
3. **找出成长机会**：对这一类，问“下次我会怎么做？”写一句。

## 模板

```
<日期>
失败：……　类型：失误 / 弱点 / 成长机会
（成长机会）下次我会：……
```

## 二、陪用户时

- 先接住情绪，再分类。用户说“我就是失败者”，回一句“这是一件事，不是你这个人”，再问“这件事属于哪一类？”
- 原型没成功不算失败，算拿到了反馈（`prototyping.md` 第五节）。
- 书里引用达克沃思关于“坚毅”的研究来说明失败免疫的价值；这部分对话里不用展开。
